### Key Features Implemented

- **`finalise-diff.sh`**: diffs the merge base of the PR's base branch against the PR head, on either forge. It asks the forge only when the head is not local or adds nothing (a merged PR, GitHub only). It writes the patch without bundled `references/` copies, plus a NUL-delimited names list. Output flags are pinned, so a user's git config cannot change the patch.
- **`<DIFF_LINE>` for the agents**: the AC and fix-evidence agents now receive the reader's line, so they can tell whether the patch holds bundled copies. The DoD's Step 2 block records it.
- **Empty-change guard**: every DoD prompt that reads the diff fails, with "the change could not be read", when it is empty. It never passes.
- **Gap body ends at the marker**: `dod-gap-count.sh --body` stops at the current and both legacy change-log start markers. A marker inside a fenced block is kept.

### Architecture/Design Decisions

There is one reader for the PR's change, and its output names its source. A failure to read is reported as `unresolved`, never replaced with the last commit. Bundled copies are listed in the names file and left out of the patch, because they are generated and `bundle:check` holds them equal to their sources.

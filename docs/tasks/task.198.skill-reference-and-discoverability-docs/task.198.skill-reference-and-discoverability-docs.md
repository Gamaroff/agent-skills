# Technical Task: Skill reference and discoverability docs

**Status:** Planned
**GitHub Issue**: [#601](https://github.com/Gamaroff/agent-skills/issues/601)

---

## 1. Overview

Make the command reference, activation phrases, workflow overviews and skill READMEs list what ships: missing flags and modes, removed or never-shipped skills, and skills absent from the maps.

**Scope**: 27 confirmed findings (12 medium, 15 low) across 15 docs, from the 2026-10-07 doc-drift audit ([report](../../../.agents/plans/doc-drift-audit-2026-10-07.md)). The plan file lists every finding with its evidence and fix.

**Key deliverables**:

1. Each listed doc says what the current sources do, finding by finding.
2. A re-check of every finding before it is edited, so a finding fixed since the audit is closed rather than re-edited.
3. Link and format checks green on every changed doc.

---

## 2. Motivation

### Current Problems

1. commands.md and activation-phrases.md miss shipped flags and modes (`/review-pr --inline`/`--effort`/work-item targets, `/review-code` targets, `/create-task --from-observation`, session-handoff continue mode, wireframe from an existing screen). Overview pages and READMEs name skills that do not exist (`document-project`, `simplify`, `qa-technical-task`, `uat-automate`) and leave out ones that do (`qa-next`, `develop-bug` dispatch, the jira-sprint-* ceremony skills, `wireframe` in create-story's map).
2. The docs predate most of the 401 commits since `v0.52.0`, so a reader following them is misled even where nothing fails outright.
3. Each finding was confirmed by an auditor and a second agent that tried to refute it, against `develop` at `a0e135a6`; none is fixed yet.

### Benefits

1. A reader following these docs gets the behaviour the skills have today.
2. The next release ships docs that match it.
3. Fewer support questions caused by docs describing behaviour that changed.

---

## 3. Technical Background

### Current Architecture

The docs below restate behaviour defined in the skill sources. They drifted because each behaviour change updated its `SKILL.md` and shared resource but not every doc that restates it.

Docs in scope (finding count):

- `docs/concepts/architecture.md` (2)
- `docs/concepts/overview.md` (2)
- `docs/operations/workflows.md` (2)
- `docs/reference/activation-phrases.md` (3)
- `docs/reference/commands.md` (4)
- `docs/reference/invocation.md` (1)
- `docs/runbooks/document-existing-project.md` (1)
- `docs/runbooks/qa-flow.md` (1)
- `docs/runbooks/sprint-cycle.md` (1)
- `docs/runbooks/story-development.md` (2)
- `README.md` (1)
- `skills/develop-next/README.md` (2)
- `skills/qa-next/README.md` (1)
- `skills/review-story/README.md` (2)
- `skills/review-task/README.md` (2)

Sources of truth: each skill's `SKILL.md` (frontmatter `description`, `invokes:`, § Arguments), `docs/reference/skill-catalog.md` (generated, fresh). Every finding's evidence is a `path:line` into these, recorded in the plan and the audit report.

### Target Architecture

Every command row, activation phrase and dependency map entry matches the shipped `SKILL.md` and its `invokes:`; no doc names a skill that is not in `skills/`.

### Important Clarifications

- **Findings are from 2026-10-07 at `a0e135a6`.** Phase 0 re-checks each against the tree at the time of work: a finding fixed since then is marked closed, not re-edited, and one whose source moved is re-cited.
- **Edit sources, not copies.** `skills/*/references/` files are generated by `npm run bundle`; no finding points at one.
- **Sibling tasks.** task.196, task.197, task.199 cover the rest of the audit. They touch different findings; where two tasks edit the same file the edits are in different sections.

## 11. Rollback Plan

### Immediate Rollback (< 1 hour)

- **Triggers**: a changed doc gives a command that fails, or the link check goes red on `develop`.
- **Steps**: 1) `git revert` the merge commit. 2) Re-run the link check.
- **Validation**: the reverted docs match `develop` before the merge.

### Partial Rollback (1-2 hours)

- **When to use**: one doc's edit is wrong. Revert that file's hunk only.

### Forward Fix (< 4 hours)

- **When to use**: a wording problem with no wrong outcome. Fix forward.

### Rollback Triggers

- **Critical**: a doc that now tells users to run a failing command.
- **Non-critical**: wording.

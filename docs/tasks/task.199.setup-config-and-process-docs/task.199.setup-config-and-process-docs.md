# Technical Task: Setup, configuration and process docs

**Status:** Planned
**GitHub Issue**: [#602](https://github.com/Gamaroff/agent-skills/issues/602)

---

## 1. Overview

Fix the install wizard, configuration, tracker and release-process docs where they no longer match the scripts: wizard steps, credential file, hooks, platform resolution, pipeline moments, release.sh's CI check, bug status mirroring.

**Scope**: 20 confirmed findings (9 medium, 11 low) across 15 docs, from the 2026-10-07 doc-drift audit ([report](../../../.agents/plans/doc-drift-audit-2026-10-07.md)). The plan file lists every finding with its evidence and fix.

**Key deliverables**:

1. Each listed doc says what the current sources do, finding by finding.
2. A re-check of every finding before it is edited, so a finding fixed since the audit is closed rather than re-edited.
3. Link and format checks green on every changed doc.

---

## 2. Motivation

### Current Problems

1. getting-started.md and release-and-install.md describe an older wizard (no tracker-workflow or access step, `.env` instead of `.secrets/tooling.env`, three hooks instead of two); configuration.md lists six pipeline moments where there are eight and an env-var step in VCS resolution that does not exist; the release runbook omits release.sh's CI-verdict check; bug docs miss the general-bug registry mirroring and the fourth Jira sync skill.
2. The docs predate most of the 401 commits since `v0.52.0`, so a reader following them is misled even where nothing fails outright.
3. Each finding was confirmed by an auditor and a second agent that tried to refute it, against `develop` at `a0e135a6`; none is fixed yet.

### Benefits

1. A reader following these docs gets the behaviour the skills have today.
2. The next release ships docs that match it.
3. Fewer support questions caused by docs describing behaviour that changed.

## 11. Rollback Plan

### Immediate Rollback (< 1 hour)

- **Triggers**: a changed doc gives a command that fails, or the link check goes red on `develop`.
- **Steps**: 1) `git revert` the merge commit. 2) Re-run the link check.
- **Validation**: the reverted docs match `develop` before the merge.

### Partial Rollback (1-2 hours)

- **When to use**: one doc's edit is wrong. Revert that file's hunk only.

### Forward Fix (< 4 hours)

- **When to use**: a wording problem with no wrong outcome. Fix forward.

### Rollback Triggers

- **Critical**: a doc that now tells users to run a failing command.
- **Non-critical**: wording.

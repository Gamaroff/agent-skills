### Key Features Implemented

- **CRLF-safe fence regex**: `[^\n]*` plus trim; a CRLF/LF control pair that can go red.
- **Named-guard hostile table**: each row pairs a path with the message of the guard that must fire.
- **One extraction path**: `boundBlockFor(site)` replaces the duplicated extraction.
- **Hardened bound block**: accepts `docs/` or the configured `PRD_ROOT`, refuses a symlinked file, and compares real paths of the parent directory against each root.

## Known Limitations & Future Work

### Current Limitations

- The lint test's margin under 2 s is thin (about 2%) and may fail on a heavily loaded machine.
- An unresolvable parent directory skips the real-path check; measured not exploitable because the read itself then fails.
- `tests/bundle-missing-source.test.js` is load-sensitive inside a full `ci:fast` run (passes alone and in CI).

### Suggested Follow-Up

- Close the unresolvable-parent edge so the real-path check does not rely on the read failing.
- Give the lint test more headroom, or move the scratch-repo tests behind their own file.

## Phase-by-Phase Implementation Guide

### Phase 1: Remote parser

**Files**: `shared/resources/jira-sync.js` (`function getBitbucketRepoBase`, near line 491), a new test file beside the existing `jira-sync-*.test.mjs` files.

Before writing, confirm the exports line (`getBitbucketRepoBase,` near `jira-sync.js:6005`) and add `parseBitbucketRemote` next to it.

Sketch:

```js
const BITBUCKET_HOSTS = new Set(["bitbucket.org", "ssh.bitbucket.org", "altssh.bitbucket.org"]);

function parseBitbucketRemote(url) {
  const s = String(url || "").trim();
  // scp-style: [user@]host:ws/repo      url-style: scheme://[userinfo@]host[:port]/ws/repo
  const m =
    /^(?:[a-z][a-z0-9+.-]*:\/\/)(?:[^@/]+@)?([^/:@]+)(?::\d+)?\/(.+)$/i.exec(s) ||
    /^(?:[^@/:]+@)?([^/:@]+):(?!\/\/)(.+)$/.exec(s);
  if (!m || !BITBUCKET_HOSTS.has(m[1].toLowerCase())) return null;
  const segs = m[2].replace(/\/+$/, "").replace(/\.git$/, "").split("/");
  if (segs.length !== 2 || !segs[0] || !segs[1]) return null;
  return `https://bitbucket.org/${segs[0]}/${segs[1]}`;
}
```

This is a starting point, not tested code: the test file decides. Points the tests must pin: the host comparison is exact and case-insensitive; userinfo never reaches the result; a port is ignored; a remote with a path of other than two segments returns `null`.

`getBitbucketRepoBase` keeps its env-var branch, then returns `parseBitbucketRemote(execSync("git remote get-url origin"))` inside the existing try/catch.

**Tests (write first, see them fail)**: seven shape cases, then `bitbucket.org.evil.example`, `github.com`, `""`, `https://user:token@bitbucket.org/w/r.git` (result must not contain `token`), and a one-segment path.

### Phase 2: Update guard

**Files**: `skills/sync-jira-{task,story,epic,bug}/scripts/*.js`.

In each script, after `const isUpdate = !!existingJiraKey` (task `:633`, bug `:742`, story `:873`, epic `:897`) and before the first write, add:

```js
if (isUpdate && !bbBase) {
  output.err(
    `Error: cannot update ${existingJiraKey}: the Bitbucket repo URL could not be derived, ` +
      `and writing the card now would remove its Source Documents links. ` +
      `Set BITBUCKET_REPO_URL=https://bitbucket.org/<workspace>/<repo> and re-run.`,
  );
  return { exitCode: 1 };
}
```

Place it after the existing `output.warn` so a create still sees only the warning. `bbBase` is defined earlier in each `main` (`:539`, `:594`, `:764`, `:782`), so no signature changes. Check each script's `--dry-run` path: it must report the same error. If a script builds its description before `isUpdate` is known, put the guard at the earliest line where both are in scope.

**Tests**: reuse each script's existing HTTP stub (`skills/sync-jira-*/tests/`), run an update with a remote the parser rejects and no env var, assert exit code 1 and an empty PUT log.

## Phase-by-Phase Implementation Guide

### Phase 1: `--copy-as` (obs #143)

**`shared/resources/qa-execute-snippets.mjs`**

- `main()` (the `switch` near `case "--copy":`): add

  ```js
  case "--copy-as": {
    const pair = argv[++i] ?? "";
    const colon = pair.lastIndexOf(":");
    if (colon < 1 || colon === pair.length - 1)
      return { exitCode: 2, error: `bad --copy-as (want SRC:DEST): ${pair}` };
    copyAs.push({ src: pair.slice(0, colon), dest: pair.slice(colon + 1) });
    break;
  }
  ```

  `lastIndexOf` so a Windows-style or colon-bearing `src` still splits on the final colon; `dest` is
  repo-relative and never contains one in practice. Thread `copyAs` into `executeFile`.
- `executeFile` (after `if (copyFrom) cpSync(copyFrom, tmp, …)`, inside the existing `try` so the
  `QA-11` cleanup contract covers it):

  ```js
  for (const { src, dest } of copyAs) {
    if (isAbsolute(dest)) throw new Error(`--copy-as dest must be relative: ${dest}`);
    const target = resolve(tmp, dest);
    if (target !== tmp && !target.startsWith(tmp + sep))
      throw new Error(`--copy-as dest escapes the working copy: ${dest}`);
    mkdirSync(dirname(target), { recursive: true });
    cpSync(src, target, { recursive: true });
  }
  ```

  A throw is already mapped to exit 2 by `main`'s `try { executeFile(…) } catch`.
- Update the header comment's option list and `USAGE`.

**Prose** — `shared/resources/qa-runnable-prose-detection.md` (the paragraph ending "set the per-block
timeout with `--timeout <ms>`"), `skills/qa-task/SKILL.md` Step 4b ("seed the temp working directory
from a real directory with `--copy <dir>`…") and `skills/qa-story/SKILL.md` Phase 1.7 (same sentence):

> `--copy <dir>` places the directory's **contents** at the temp root. When a block addresses a
> path — `find docs/tasks …` in the `sync-github-*` discovery blocks — seed it at that path with
> `--copy-as docs:docs` (repeatable). A block that fails because it was seeded at the wrong path is a
> harness finding, not a prose finding (obs #143).

**Tests** — `shared/resources/tests/qa-execute-snippets.test.mjs`: build a fixture tree
`<fixture>/docs/tasks/a.md`; the markdown under test holds one block, `ls docs/tasks`. Assert:
`copyAs: [{ src: "<fixture>/docs", dest: "docs" }]` → no findings; `copyFrom: "<fixture>/docs"` →
one `execution-failure` (both directions, so the test cannot pass on a harness that ignores
`copyAs`). Two pairs both land. `dest: "../x"` and `dest: "/tmp/x"` throw, nothing named `x` appears
beside the temp root, and the `qa-snippets-` temp-dir count is unchanged (copy the `QA-11` counting

**`shared/resources/change-log.js`** — add and export:

```js
function checkUpdatedCoherence(content) {
  const rows = extractEntries(content);
  if (!rows.length) return { ok: true, reason: "no-log" };
  // RE_ENTRY_ROW admits an optional ` HH:MM` after the date; compare the date part only.
  const dates = rows.map((r) => (r.match(/^\|\s*(\d{4}-\d{2}-\d{2})/) || [])[1]).filter(Boolean);
  const newest = dates.sort().at(-1);
  const updated = (content.slice(0, bodyStart(content)).match(/^updated:\s*['"]?(\d{4}-\d{2}-\d{2})/m) || [])[1];
  if (!updated) return { ok: true, reason: "no-updated", newest };
  return newest > updated
    ? { ok: false, reason: "stale-updated", newest, updated }
    : { ok: true, reason: "ok", newest, updated };
}
```

`extractEntries` returns table-line strings (`splitCarriedLines(...).tableLines.filter(isEntryRow)`,
with `RE_ENTRY_ROW` = `/^\|\s*\d{4}-\d{2}-\d{2}(?:\s+\d{2}:\d{2})?\s*\|/`).
Add a `require.main === module` CLI: `--check-updated --file <doc> [--json]`, exit 0 / 1 / 2, and set
`process.exitCode` rather than calling `process.exit()` after a write (bug.3; the repo guard is red on
a new file that does it).

## How to Read These

These epics were all created from the same PRD in one session. Use them to:

- Pattern-match structure (Goal, Scope, Acceptance Criteria, Story Breakdown)
- Compare tone and depth across different epic sizes (Epic 1 has 5 stories, Epic 3 has 3)
- Understand how `/create-epic` translates PRD requirements into actionable epics

Each captured copy has provenance frontmatter (`captured_skill_version`, `captured_date`, `source_sha`, `source_path`) recording the exact state at capture time.
